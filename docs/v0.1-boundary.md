# v0.1 Boundary: Knowledge-as-Code

This repository is an executable v0.1 packet for **knowledge artifacts as code**.

## Scope

- Represent source packets, claims, vocabularies, citations, and acceptance state as reviewable source.
- Make evidence provenance explicit and boundary-aware.
- Keep conceptual claims testable with explicit source links and review records.

## Non-canon posture

This repository is `seed`/`v0.1-draft` only until explicitly adopted by HUMMBL authority.

## Boundaries

- Do not use this repo as legal or policy authority.
- Do not mix source receipts and interpretation without explicit provenance fields.
- Do not overextend claims beyond available source evidence.
- Keep transformation logic explicit and bounded.

## Initial practical user

Teams turning source material into governed, reusable knowledge assets that need:

- claim identity and retrieval metadata,
- interpretation records,
- explicit evidence status,
- review/acceptance receipts.
